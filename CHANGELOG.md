# Changelog

## 3.0.0 (final study)

- Patient-grouped nested cross-validation over five seeds with patient-level bootstrap intervals.
- PCA and GA feature fusion (R2, R3), UAGF, cross-attention, NSGA-II Pareto fusion and MC-dropout referral.
- Shortcut probes, shuffled-label and thumbnail controls, matched-type evaluation, harmonisation ablation and cross-dataset tests.
- CSC OCT Analyser web app with live progress, Grad-CAM, PDF reports and a public mode that keeps no shared history.

## 2.0.0

- Leak-free rewrite with UAGF; found that image size alone separates the OCT-C8 classes.

## 1.0.0

- Original eight-backbone benchmark on Retinal OCT-C8 (single epoch, image-level split).
